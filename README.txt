FNAF RPG — A ÚLTIMA NOITE

COMO ABRIR (MAIS FÁCIL):
1. Extraia esta pasta inteira.
2. Entre na pasta FNAF_RPG_Final.
3. Dê dois cliques em INICIAR_JOGO.bat.
4. O navegador abrirá automaticamente o jogo.
5. Clique em COMEÇAR JOGO.
6. NÃO feche a janela preta do servidor enquanto estiver jogando.

ALTERNATIVA:
Abra a pasta no VS Code e use uma extensão de servidor local (como Live Server) para abrir o index.html.

IMPORTANTE:
- O navegador pode bloquear áudio automático. O botão COMEÇAR JOGO tenta iniciar a música depois do primeiro clique.
- As artes disponíveis cobrem a introdução e as cenas 1–5. As cenas 6–16 usam temporariamente a arte da Cena 5 como fundo.
- A história e as escolhas foram adaptadas do RPG enviado.

ARQUIVOS:
index.html -> estrutura da página
style.css -> visual do jogo
main.py -> lógica do RPG em PyScript
musica.mp3 -> trilha enviada
assets/ -> imagens das cenas
INICIAR_JOGO.bat -> inicia um servidor local e abre o jogo no navegador
